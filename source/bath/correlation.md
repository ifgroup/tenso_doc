# Correlation

## Quick setup

- Development setup: 

    0. Create a conda virtural environment with python vesion >= 3.10.

    1. Prepare dependencies: `numpy`, `scipy`, `pytorch`, `torchdiffeq`, `tqdm`

    2. Clone the repository:

            git clone https://github.com/ifgroup/tenso.git

    3. Install `pytenso` in develop mode using `pip`:

            pip install -e .

    4. For testing, consider `jupyter-lab`, `matplotlib`, etc.
