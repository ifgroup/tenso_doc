Reporting issues
----------------

Bug reports, feature requests, and questions are welcome via the
`GitHub issue tracker <https://github.com/ifgroup/pytenso/issues>`_.

Contributing
------------

Contributions are welcome. Please open an issue to discuss your proposed
change before submitting a pull request. All contributions should include
appropriate tests and documentation updates.

The source code is available at
`https://github.com/ifgroup/pytenso <https://github.com/ifgroup/pytenso>`_.
